# java-lotto-precourse

## 입출력 기능

- 입력
    - 구입 금액 입력
    - 당첨 번호 입력
    - 보너스 번호 입력
- 출력
    - 구매한 로또 번호 목록 출력
    - 당첨 통계 출력
        - 일치 출력 : "n개 일치 (x,xxx,xxx원) - n개"
        - 수익률 출력 : 총 수익률 두번째 자리에서 반올림
    - ERROR 메시지 출력

## 당첨 개수 및 금액

- 고정된 값이므로 상수화하여 관리

## 파싱 기능

- 구입 금액 파싱
    - 빈 문자열인가?
    - 숫자인가?
    - 1000원으로 나누어 떨어지는가?
- 당첨 번호 파싱
    - 빈 문자열인가?
    - 입력 포맷이 일치하는가?
    - 6개의 수인가?
    - 1~45의 수인가?
- 보너스 번호 파싱
    - 빈 문자열인가?
    - 숫자인가?
    - 1~45의 수인가?

## 에러 메시지 처리 구체화

- 구입 금액 파싱 시 메시지 처리
- 당첨 번호 파싱 시 메시지 처리
- 보너스 번호 파싱 시 메시지 처리

## 로또 머신 기능

- 구입금액, 당첨번호, 보너스 번호를 순차적으로 입력 받도록 함
    - 예외가 발생한다면 메시지를 출력하고 해당 부분부터 다시 시도
- 통계 기능
    - 몇 등을 몇 번 당첨했는가?
    - 수익률은 몇 퍼센트인가?
